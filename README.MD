MicroAmp is a feature-packed, zero-dependency retro media player compressed entirely into a single 71KB standalone file.
Inspired by the peak desktop era of Winamp and late-90s hardware audio modules, MicroAmp pairs a deeply nostalgic aesthetic with modern hardware-level system integration. Built purely using native web technologies via conversational AI and advanced prompt engineering, it runs closer to the browser's bare metal for instantaneous load times and zero system bloat.

⚡ Key Features

• Adaptive UI Color-Theming: The entire user interface accent color dynamically morphs in real time to match the visual identity and dominant color of your active album cover artwork.
• Real-Time 16-Bit Image DSP: A custom graphics renderer automatically processes raw digital album art and national artist flags into vintage, dithered 16-bit pixel aesthetics.
• Click-to-Seek Synced Lyrics: Features an auto-following lyrics display window. Click directly on any individual line of text to instantly warp the audio timeline straight to that verse.
• 10-Band Biquad Hardware EQ: Fine-tune your acoustics using a responsive studio equalizer. Includes an analog-style bypass toggle switch to route audio past the filters for clean, unaltered playback.
• Deep Operating System Integration: Hooks directly into native system architecture via the Media Session API, allowing physical keyboard media hotkeys, headphones controls, and system lock screen widgets to control playback.
• Launcher Window Management: Manage your music vault through an integrated desktop file ecosystem featuring intuitive "click-outside" light-dismissal window closure.

💾 Performance & Portability

• Microscopic Footprint: The entire fully-featured engine is streamlined into just 71KB.
• 100% Offline Capability: Take your music player anywhere. It functions perfectly on airplanes, remote travel, or deep underground without ever needing an active internet connection.
• Cross-Platform Compatibility: Runs with identical, pixel-perfect fidelity across Windows, macOS, Linux, Android, and iOS via any standard native web browser.
• Absolute Privacy: MicroAmp operates entirely client-side. Your local music library is loaded straight into your local browser cache and never touches a third-party server.

🚀 How to Use

1. Download the standalone MicroAmp.html file to your device.
2. Double-click the file to open it instantly inside any web browser.
3. Click + ADD FOLDER or + ADD FILES to locally load your audio archive.
4. Optional: To load synchronized lyrics, simply place a standard .lrc file in the same directory as your audio file with the exact same name.
